# Changelog

## 1.0.0

- The Hotspots tool window: a heat map of the codebase from its own git history, sized by lines of code and coloured by risk,
  with zoom, filter, hover details and a panel for each file.
- Five colour modes: Hotspots, Change frequency, Complexity, Code age and Knowledge risk.
- Top Hotspots, Changes Together and Knowledge Risks.
- Flames and ranks on the hottest files in the Project view; the open file's rank in the status bar.
- Why Is This a Hotspot?, Open Files That Change With This One, File History with each commit's diff, and a Markdown report.
- One person with several names or emails counts once; `.mailmap` is respected.
- Settings → Tools → Hotspots Veyra: period, flames, status bar and excluded files. Refreshes after commits, pulls and checkouts.
