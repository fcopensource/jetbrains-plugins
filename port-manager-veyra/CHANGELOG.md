# Changelog

## 1.0.0

- A live **Ports** tool window: every listening port, grouped into This Project, Apps & Dev Servers, Editors & Tools and System
- Recognises 50+ dev servers, runtimes and databases from the program and its command line
- Open in Browser, Copy Address, Stop and Reveal Folder; Free a Port… stops whatever holds a port; Hide This Port
- A notification when your project's dev server starts, with Open in browser and Stop
- A status-bar counter of the ports your apps are using
- System services, other users' programs and JetBrains IDEs are protected and can never be stopped
- Windows, macOS and Linux
