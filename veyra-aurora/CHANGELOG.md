# Changelog

## 1.0.0

- Veyra Aurora and Veyra Aurora Light: the northern lights, with ice-blue keywords, aurora-green strings, teal functions,

- Matching editor colour schemes for every language, the debugger, diffs, VCS, search and the terminal.
- Every syntax colour meets WCAG AA contrast on its background, comments included.
