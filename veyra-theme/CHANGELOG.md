# Changelog

## 1.0.1

- A new icon: an editor window framed in the FlightCoders gradient, with code in the theme's own colours.

## 1.0.0

- **Veyra Dark** and **Veyra Light**, in the FlightCoders colours: coral, amber and violet on deep ink.
- Every part of the IDE themed, with the rounded Islands look on 2025.3 and newer.
- Matching editor colour schemes for every language, the debugger, diffs, VCS, search highlights and the terminal.
- Signature details: coral-to-violet default buttons, a coral caret and tab underline, an amber current line number
  and an amber-to-violet progress bar.
- Supports every JetBrains IDE from 2024.3.
