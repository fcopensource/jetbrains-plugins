# Changelog

## 1.0.0

- Earn aura for clearing every error in a file, clean saves, commits (and good commit messages), passing tests and builds,
  big deletes, locked-in sessions and late nights.
- Roast mode: lose a little for "wip" commit messages, failing tests and builds, and leftover debugger statements.
- Eight ranks from NPC to Final Boss, a daily streak with a bonus, and daily limits so aura can't be farmed.
- Your aura in the status bar with each move as it happens, and a notification when you rank up.
- The Aura tool window: rank and progress, streak, the week, best moves, every move and the rank ladder.
- Share My Aura Card: a 1200 × 630 image and a caption copied to the clipboard.
- Commits from Git (any tool), tests from the IDE's test runner, builds from Build Project. 100% local.
