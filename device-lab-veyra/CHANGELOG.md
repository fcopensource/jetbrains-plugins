# Changelog

## 1.0.0

- Device Lab tool window: theme, font size up to 200 %, display size, app language (with pseudolocales), right-to-left, animations, layout bounds, show taps, airplane mode and a clean status bar, each in one click
- Presets: Worst case, Screenshot ready, Slow motion, and Reset, which puts the device back as it was
- Your app: grant or revoke runtime permissions, open the deep links from your manifest and Navigation graphs (with the screen that opened and its start time), restart, clear data, screenshot into the editor
- Emulators and real phones, Android 8 and newer; finds adb by itself
